# 📋 Changelog — Live Chat Application

All notable project updates and documentation changes are recorded in this file.

The project is developed using HTML5, CSS3, and Vanilla JavaScript.

---

## [1.0.0] — Initial Release

### ✨ Application Features

- Real-time cross-tab messaging using the BroadcastChannel API.
- Modern chat interface with responsive layout.
- Custom dark-themed chat background.
- Separate message bubbles for sent and received messages.
- Message timestamps.
- Send messages using the Send button or Enter key.
- Automatic scrolling to the latest message.
- Tab join and leave notifications.
- Active tab tracking using heartbeat messages.
- Active status indicator.
- Smooth CSS animations.

### 🛠️ Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- BroadcastChannel API
- DOM API

## ⚠️ Known Limitations

- Communication is limited to compatible browser contexts sharing the same origin and storage partition.
- Messages are not permanently stored.
- No backend server or database is implemented.
- No user authentication is available.
- Cross-device messaging is not supported.
- Inactive tabs are not automatically removed after every missed heartbeat.
