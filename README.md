# 💬 Live Chat Application

### A Real-Time Cross-Tab Chat Application Using HTML, CSS & JavaScript

A modern and responsive frontend chat application that allows users to communicate between multiple browser tabs in real time using the JavaScript BroadcastChannel API.

This project is developed using pure HTML, CSS, and JavaScript without any external frameworks or backend server.

---

## 🚀 Features

- 💬 Real-Time Cross-Tab Messaging
- 🌐 BroadcastChannel API Integration
- 🎨 Modern and Responsive Chat Interface
- 🌙 Dark-Themed Chat Background
- 👥 Active Browser Tab Detection
- 🟢 Active Status Indicator
- ⏰ Message Timestamps
- 📩 Instant Message Delivery
- 🔔 Tab Join and Leave Notifications
- ⌨️ Send Messages Using Enter Key
- 📱 Responsive Layout
- ⚡ Lightweight Frontend Application

## ⚙️ Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Step 2: Open the Project

Navigate to the project directory.

### Step 3: Run the Application

Open `index.html` in a modern web browser.

### Step 4: Start Chatting

1. Open the application in one browser tab.
2. Open the same application in another tab.
3. Type a message in the input field.
4. Click Send or press Enter.
5. Messages will appear in the connected tabs.

---

## 🔄 How It Works

The application uses the JavaScript BroadcastChannel API.

When a user sends a message:

1. JavaScript captures the message.
2. The message appears in the sender's chat interface.
3. BroadcastChannel sends the message to other connected tabs.
4. Receiving tabs display the message instantly.

No backend server or database is required.

**Note:** This is a browser-based cross-tab chat application, not an internet-wide messaging service. Messages are not permanently stored.
